# Shinka releases

Installers for Shinka, a local Windows app for AI sky images and videos.

Download `Shinka_<version>_x64-setup.exe` from the newest release under **Releases** and run it.
Windows may show "Windows protected your PC", because the installer is not code-signed. Click **More info → Run anyway**.

Installed copies look here for updates and offer "Update now". Each update is signed, and Shinka checks the signature before it installs it.
